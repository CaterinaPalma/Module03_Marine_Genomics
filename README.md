# marine-genomics
Metagenome assembly of Black Band Disease (BBD). 

We use a web-based rstudio to throughout this module. Very cool because it means we are able to log into our work even if we don't have our personal computer. 

In this repository you will find my RMarkdown files that present the code I wrote for workshops 1-4. 
Throughout the module we ran the genome assembly of BBD given to us, but it is only 10% of the full genome. 
We were still able to identify the most common microbes found in BBC, cyanobacteria, Sulfate-reducing bacteria, and Sulfide-oxidising bacteria. 

Please take a look through if you're interested in how we used rstudio to identify genome sequences in a genome assembly!
